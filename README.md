# 🏦 TechBalance Solutions — Landing Page

> Landing page da **TechBalance Solutions**, empresa fictícia criada como parte do seminário da disciplina de **Contabilidade**. O projeto consiste no desenvolvimento de um **ERP contábil** personalizado para micro e pequenas empresas, onde a TechBalance Solutions é a empresa fictícia responsável pelo produto.

🔗 Veja o case completo (ContaUp) no [portfólio de Guilherme Rodrigues](https://www.gui-ccr.com.br/project/contaup).

## ⚡ Stack

- ⚡ **Vite 6** — bundler e dev server
- ⚛️ **React 18** — interface
- 🎨 **Tailwind CSS v4** — estilização (CSS-first, sem `tailwind.config.js`)
- 🟨 JavaScript puro (sem TypeScript)

---

## 🚀 Como rodar

```bash
# instalar dependências
npm install

# servidor de desenvolvimento
npm run dev

# build de produção
npm run build

# preview do build
npm run preview
```

---

## 📁 Estrutura

```
src/
├── main.jsx
├── index.css          # @theme tokens + base reset + classes JS-toggled
├── App.jsx
└── components/
    ├── Icon.jsx        # ícones SVG inline
    ├── Header.jsx      # Header, Hero, useReveal, useScrolled
    ├── Sections.jsx    # Problem, Solution, Features, Comparison, Audience, MissionVision, Team
    └── ContactFooter.jsx  # Contact, CTA, Footer
public/
└── assets/            # logos da marca
```
